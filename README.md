# 🏎️ Open Road Racer

A high-performance racing game for mobile browsers. Drive fast, reach top speeds, and experience arcade-style racing directly in your iPhone Safari!

## 🎮 Play Now

**Open this link on your iPhone Safari:**
```
https://7j2zrfjgsb-eng.github.io/open-road-racer/
```

Or visit: https://github.com/7j2zrfjgsb-eng/open-road-racer

## 🎯 Controls

### Mobile (Touch)
- **◀ / ▶** - Steer left/right
- **GAS** - Accelerate
- **BRAKE** - Brake

### Keyboard (Testing)
- **Arrow Keys** or **WASD** to control
- **Up** - Accelerate
- **Down** - Brake

## 📊 Features

✅ **Fully Optimized for iPhone**
- Works in Safari without any app download
- Responsive touch controls
- Full-screen support with safe area awareness
- Smooth 60 FPS performance

✅ **Realistic Driving Mechanics**
- Smooth acceleration and braking
- Speed-dependent steering sensitivity
- Max speed: 220 KM/H
- Automatic gear shifting (D, 3, 4, 5)

✅ **3D Graphics**
- Real-time 3D rendering with Three.js
- Dynamic shadows and lighting
- Infinite looping road
- Responsive camera

## 🚀 How to Run

### Option 1: Play Online (Recommended)
Simply open the GitHub Pages link above in Safari on your iPhone.

### Option 2: Run Locally

```bash
# Clone the repository
git clone https://github.com/7j2zrfjgsb-eng/open-road-racer.git
cd open-road-racer

# Start a local server
python3 -m http.server 8000
# or
npx http-server

# Open in browser
# http://localhost:8000
```
